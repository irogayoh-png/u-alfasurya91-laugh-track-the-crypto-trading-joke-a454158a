Entry for the [make.fun bounty "Laugh Track: The Crypto Trading Joke Contest"](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a).

The program writes exactly one joke about crypto and trading life to `/output/entry.txt` (99 characters, one line, no trailing newline):

> I told the group chat this was the bottom, so the chart dug a basement, added a pool, and moved in.

The setup is the trader ritual of calling the bottom in the group chat; the chart digs a basement, adds a pool, and moves in — a payoff that escalates twice and lands at the very end. The line won this session's arena against five other shortlisted lines and cleared the gold-set bar (see ARENA.md, kept outside this repo).

Run it locally without touching the shared `/output`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/laugh-track-out python3 main.py
```
